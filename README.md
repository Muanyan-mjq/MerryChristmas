# Merry Christmas

A single-file, fully offline Christmas tree page (canvas, no external assets).

Live: https://muanyan-mjq.github.io/MerryChristmas/

- `index.html` — the whole page (paint-style tree, knitted scarf ribbon, 7 themes, tri-lingual handwriting)
- `.nojekyll` — serve the HTML as-is, skip Jekyll processing
